# Credit Risk Analysis & Loan Repayment Behaviour Using EDA

## Project Overview

This project analyzes loan application data to identify credit risk patterns, approval trends, customer behavior, and financial insights.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- SQL
- Streamlit

## Project Workflow

1. Data Cleaning
2. EDA
3. SQL Analysis
4. MySQL Integration
5. Streamlit Dashboard

## Dashboard Features

- KPI Cards
- Loan Status Analysis
- Risk Analysis
- Client Type Analysis
- Seller Industry Analysis
- SQL Query Results

## Business Insights

- Most applications are approved.
- Repeater clients contribute significantly.
- Consumer loans dominate applications.
- Some industries receive higher credit allocation.

## Conclusion

Credit risk patterns can be identified through application status, client behavior, and financial indicators.
