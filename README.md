# Credit Risk Analysis & Loan Repayment Behaviour

## Project Overview
This project analyzes customer loan repayment behavior and credit risk using EDA, SQL, MySQL, and Streamlit Dashboard.

## Tools Used
- Python
- Pandas
- NumPy
- MySQL
- SQL
- Streamlit
- Plotly

## Project Workflow
1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis (EDA)
3. MySQL Database Integration
4. SQL Query Analysis
5. Streamlit Dashboard Development
6. Business Insights & Recommendations

## Key Features
- Credit Risk Analysis
- Loan Repayment Behaviour Analysis
- Interactive Dashboard
- SQL-Based Business Insights
